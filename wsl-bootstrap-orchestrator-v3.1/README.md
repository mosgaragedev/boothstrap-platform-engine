# 🚀 WSL Bootstrap Orchestrator v3.1

## One Command Deployment

```powershell
./bootstrap.ps1
```

## What it does

- Installs WSL
- Imports custom distro
- Installs:
  - Podman
  - DevPod
  - GitHub CLI
  - Azure CLI
- Creates structured workspace

## Result

Fully functional enterprise dev environment.

## Requirements

- Windows 11
- Admin privileges
- rootfs.tar present in same directory
